## Architecture

- Generic typed PRE: general_rotation_original_pre_field_transport_v1.py. Raw fields, source APL row/list/time identity, single original action_ready call.
- Generic exact-method bridge: general_rotation_original_method_witness_v1.py. One reusable same-process action_t* pointer producer, source-row/ptr/method-event/Native-attempt pairing; bounded Boolean condition replay through existing Condition IR and GateContract; no class, specialization, spell or boss branch.
- SpecAdapter: supplies source-pinned individual method body, field names, method identity and source row, and a bounded passive original guard witness. Does not copy/reimplement generic marker parser.
- Independent source-run validator: verifies official original C++/profile Git blobs, actual patched producer bytes, same-seed original vs instrumented performed-action parity and source-scoped raw PRE. A caller-provided source_verified flag is NOT itself authentication.
- WCL/General Rotation/Dummy: separate independent strict-PRE candidate/holdout validation and observability-gated practice evaluation. Source PRE is NOT WCL STRICT PRE.

Generic method markers use the pair (marker prefix, source method identity). Two overrides can share a producer marker prefix, and a method identity need not equal the APL action name. Same-timestamp or foreign action_t* observations cannot prove readiness for another action. Missing method entry remains UNKNOWN, even if numeric raw values happen to match a source expression.

A FALSE independently witnessed necessary predicate may certify scoped NOT_READY. A TRUE necessary predicate does not yield complete READY until every other condition and a reviewed exhaustive virtual source route is closed. No user dummy error is established by this engine.
